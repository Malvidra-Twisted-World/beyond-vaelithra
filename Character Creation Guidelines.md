# Character Creation Guidelines — Kartaloka

> Terkait: [[Design Document]] · [[Factions]] · [[Districts]] · [[Discord Setup]]

Panduan ini buat player yang mau bikin fixer baru. Tujuannya bukan membatasi kreativitas — tujuannya memastikan karakter kalian **masuk akal ada di kota modern-fantasy Kartaloka**, bukan karakter dungeon-crawl generik yang ditempel paksa ke sini.

---

## 1. Starting Point

- **Level start:** 3 (bukan 1) — biar langsung punya subclass/fitur dasar, cocok buat mission Tier I pertama tanpa kerepotan.
- **Party Tier:** otomatis Tier I (Lv 1-4). Lihat §2.2 [[Design Document]] soal cara naik ke Tier II.
- **Trust Tier:** semua mulai di `Unknown` di semua faksi (lihat §4.4 [[Design Document]]), KECUALI background kalian secara eksplisit kasih satu faksi mulai di `Known` (lihat §4 di bawah).
- **Gold/starting fund:** pakai starting equipment kelas standar, dikonversi ke uang kartal (mata uang Kartaloka, 1:1 sama gold standar D&D — tidak perlu exchange rate ribet).

---

## 2. Species/Race — Apa yang Lumrah di Kartaloka

Semua race standar tersedia, tapi **frekuensi kemunculannya di kota beda-beda** — ini bukan pembatasan mekanis, cuma kalibrasi rasa supaya kota tetap terasa grounded urban, bukan fantasy race soup.

| Kategori | Race | Rasa di Kartaloka |
|---|---|---|
| **Umum** | Human, Half-Elf, Half-Orc, Tiefling | Populasi mayoritas kota. Tiefling tidak dianggap aneh — sudah lama jadi bagian masyarakat, paling banter dapat komentar kecil di tempat kerja konservatif. |
| **Cukup umum** | Dwarf, Gnome | Banyak kerja di sektor engineering/artificing (cocok sama Adikarsa Group atau bengkel independen) dan finance (dwarf, stereotip perbankan lama). |
| **Ada, tapi minoritas kentara** | Elf (High/Wood), Halfling | Elf biasanya di sektor akademik/Script Order atau ekspatriat dari region lain Dewanegara. Halfling banyak di sektor kuliner/logistik kecil. |
| **Jarang, selalu ada alasan personal kenapa mereka di kota** | Dragonborn, Aasimar, Genasi | Kehadiran mereka layak dapat 1-2 kalimat backstory kenapa mereka jauh dari kampung halaman "khas fantasy" mereka dan berakhir di kota industri modern. |
| **Butuh approval + hook khusus dari DM** | Race yang jelas non-humanoid/berat sisi supernatural (misal Changeling, Shifter, Warforged/construct-race, Fiend-blooded berat) | Bukan dilarang — tapi kemunculan mereka otomatis menarik perhatian [[Factions#The Script Order|The Script Order]] atau [[Factions#Scale Division|Scale Division]] secara in-world (mereka "tercatat"). Diskusikan dulu sama DM biar kehadiran mereka jadi hook, bukan sekadar reskin. |

> **Prinsip:** race exotic bukan dilarang, tapi harus punya alasan kenapa mereka spesifik ada di kota modern ini — bukan default "karena PHB mengizinkan."

## 3. Class — Reflavor Naratif, Bukan Mekanik Baru

Semua class 5e tetap dipakai apa adanya secara mekanik. Yang berubah cuma **bagaimana kalian menjelaskannya di dunia**. Pakai tabel ini sebagai starting point, boleh dikombinasi/dimodifikasi sesuai backstory kalian:

| Class | Reflavor Umum di Kartaloka |
|---|---|
| **Fighter** | Eks-militer, kontraktor keamanan swasta, mantan atlet bela diri profesional, atau penegak hukum lepas. |
| **Rogue** | Pencuri jalanan, mantan hacker (skill "Sleight of Hand" bisa direfleksikan ke fisik ATAU digital tergantung archetype), informan, atau operator lapangan sindikat. |
| **Wizard/Sorcerer/Warlock** | Caster — WAJIB tentukan status lisensi kalian (lihat §3.1 di bawah). Warlock terutama cocok punya patron yang terkoneksi ke [[Factions#The Night Remnant|The Night Remnant]] atau entitas dari era Sundering War. |
| **Cleric** | Rohaniwan aktif (termasuk kemungkinan dari institusi Silver Light yang sudah mapan di era ini — lihat §1.2 [[Design Document]]), atau chaplain rumah sakit yang bekerja berdampingan sama dokter medis. |
| **Druid** | Jarang di pusat kota, lebih masuk akal berasal dari/beroperasi di [[Districts#The Fringe|The Fringe]] atau pinggiran non-urban Dewanegara yang baru pindah ke Kartaloka. |
| **Bard** | Performer klub di [[Districts#Lantern District|Lantern District]], jurnalis, social media influencer, atau negosiator profesional. |
| **Ranger** | Bounty hunter, penjaga hutan/pinggiran kota, atau spesialis satwa liar urban (termasuk satwa yang "tersentuh" fenomena Fringe). |
| **Monk** | Praktisi bela diri dari dojo/sasana tradisional yang masih bertahan di tengah kota modern, atau disiplin spiritual pribadi. |
| **Paladin** | Oath terikat institusi (bisa ke Scale Division, Script Order, bahkan korporat kalau Oath-nya nyeleneh/gray — lihat archetype Oathbreaker/Vengeance untuk versi lebih kompleks) atau ke prinsip personal. |
| **Artificer** | Engineer independen, staf R&D Adikarsa Group, atau tukang reparasi ward/gadget lepasan. Class paling "at home" secara tematik di Kartaloka. |
| **Barbarian** | Jarang, tapi kuat kalau ada alasan: mantan pekerja kasar ekstrem, seseorang yang "tersentuh" fenomena Night Remnant hingga memicu rage sebagai respons trauma/primal, atau dari komunitas non-urban di luar kota. |

### 3.1 Caster — Status Lisensi (Wajib Ditentukan)

Semua karakter dengan spellcasting (kecuali yang jelas-jelas innate seperti sorcerer bloodline atau warlock pact — itu pun tetap kena aturan ini kalau castingnya *terdeteksi publik*) harus pilih salah satu:

- **Licensed** — terdaftar resmi di [[Factions#The Script Order|The Script Order]]. Mulai dengan Trust Tier `Known` otomatis dengan Script Order. Konsekuensinya: sihir kalian "sah" di mata hukum, tapi Script Order tahu kalian ada dan bisa memanggil/meminta sesuatu sewaktu-waktu.
- **Unlicensed** — praktik diam-diam atau baru belajar sendiri. Tidak dapat Trust Tier bonus, TAPI risiko: kalau ketahuan pakai magic signifikan di depan umum atau di TKP, ini bisa memicu perhatian [[Factions#Scale Division|Scale Division]] atau Script Order sebagai hook cerita (bukan hukuman otomatis — DM pakai ini sebagai world reactivity, bukan gotcha).

## 4. Background — Koneksi ke Dunia Kartaloka

Background standar 5e tetap dipakai, tapi setiap background **wajib** dijawab dengan 2-3 kalimat: *kenapa karakter ini jadi fixer, dan lewat siapa/apa mereka pertama kali dengar soal The Switchboard?*

Beberapa pemetaan background → Trust Tier starting bonus (opsional, boleh dilewati kalau backstory kalian tidak menyentuh faksi manapun secara langsung):

| Background | Contoh Reflavor | Trust Tier Starting Bonus (opsional) |
|---|---|---|
| Criminal/Spy | Eks-anggota kecil sindikat, atau informan lepas | `Known` dengan [[Factions#The Wave Family|The Wave Family]] |
| Soldier/Folk Hero | Eks-militer atau eks-relawan komunitas | `Known` dengan [[Factions#The Beacon Circle|The Beacon Circle]] atau [[Factions#Scale Division|Scale Division]] (pilih salah satu) |
| Guild Artisan/Merchant | Kerja dulu di sektor korporat atau reparasi teknis | `Known` dengan [[Factions#Adikarsa Group|Adikarsa Group]] |
| Sage/Acolyte | Pernah belajar/berafiliasi akademik-magis | `Known` dengan [[Factions#The Script Order|The Script Order]] |
| Hermit/Outlander | Datang dari luar kota atau dari pinggiran | `Known` dengan [[Factions#The Night Remnant|The Night Remnant]] (opsional, hanya kalau memang cocok sama backstory) |
| Urchin/Charlatan | Besar di jalanan kota | Tidak otomatis dapat faction bonus — tapi dapat kenal baik NPC hub (Ibu Tumini/Reno), fine buat RP hook |

> Cuma boleh pilih **satu** bonus starting Trust Tier per karakter, dan itu pun opsional — jangan dipaksakan kalau tidak natural dari backstory.

## 5. Equipment — Reflavor Perang Modern-Fantasy

Statistik senjata/equipment 5e **tidak diubah**, cuma dijelaskan ulang biar terasa modern. Pakai tabel ini sebagai rujukan reflavor, bukan aturan baku — sesuaikan sama konsep karakter kalian:

| Item 5e | Reflavor Modern |
|---|---|
| Dagger | Pisau lipat / combat knife |
| Shortsword | Baton taktis / machete pendek |
| Longsword | Machete panjang / pedang seremonial (kalau karakter dari komunitas tradisional) |
| Light Crossbow | Pistol semi-otomatis |
| Hand Crossbow | Pistol kompak/silenced |
| Heavy Crossbow | Shotgun |
| Longbow | Rifle jarak jauh (sniper-style, bukan berarti sniper scope penuh — sesuaikan narasi) |
| Shield | Rompi taktis / riot shield (untuk role security) |
| Leather/Studded Armor | Jaket kulit/taktis biasa |
| Chain Shirt | Rompi anti peluru ringan |
| Plate/Half-Plate | Riot gear lengkap (biasanya cuma masuk akal buat karakter dari institusi resmi seperti Scale Division atau kontraktor keamanan swasta) |
| Component Pouch (caster) | Kit reagent kecil, atau — untuk Licensed caster — perangkat ber-ward resmi dari Script Order |
| Thieves' Tools | Lockpick set ATAU laptop/hacking kit kecil (pilih sesuai konsep, tetap pakai proficiency bonus yang sama) |
| Healer's Kit | Kit P3K modern |

**Uang tunai vs digital:** kartal kota bisa dipegang tunai atau lewat *Signal* (app pembayaran, lihat §1.3 [[Design Document]]) — flavor saja, tidak ada bedanya secara mekanik. Payout mission dari The Ledger otomatis masuk dompet *Signal* karakter kecuali klien secara spesifik bayar tunai/barang.

## 6. Checklist Cepat Sebelum Submit Karakter

- [ ] Level 3, class + subclass sudah dipilih
- [ ] Race dipilih, dan kalau masuk kategori "jarang"/"butuh approval" di §2, sudah ada 1-2 kalimat alasan
- [ ] Kalau caster: sudah tentukan Licensed/Unlicensed (§3.1)
- [ ] Background dipilih + 2-3 kalimat kenapa jadi fixer & lewat siapa kenal The Switchboard
- [ ] (Opsional) satu Trust Tier starting bonus dipilih kalau relevan (§4)
- [ ] Equipment direflavor sesuai konsep (§5) — statistik tidak berubah
- [ ] Post sheet lengkap di `#character-sheets`

Kalau ragu soal race/class/background aneh yang tidak masuk tabel, tanya Dungeon Master dulu sebelum submit — biasanya cuma butuh 1-2 kalimat justifikasi, bukan penolakan.
